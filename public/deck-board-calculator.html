HOW THE SPACING HELPER WORKS

Determine deck board spacing before calculating board count

Deck board spacing is not one universal number. Traditional wood changes mainly with moisture across its width, while composite and PVC products have product- and fastener-specific gapping requirements. The helper uses common manufacturer guidance for the cases listed above, fills the side-to-side gap, and then uses that value in the row-count calculation.

For dry or acclimated traditional wood, the planning value is 1/8 inch. Fresh pressure-treated wood is shown as a tight initial installation because it commonly shrinks as it dries. Trex composite is set to 3/16 inch width-to-width. TimberTech Composite with CONCEALoc is set to 3/16 inch. TimberTech Advanced PVC has a manufacturer range of 1/8 to 1/4 inch depending on the fastening system, so this calculator uses the 1/8-inch minimum only as a planning starting point and tells you to verify the exact system.

If your product is not listed, select Other product / manufacturer-specific spacing and enter the side-to-side gap from its current installation guide. This calculator intentionally does not guess an unverified product-specific value.

SOURCE CHECK

Why the recommended gap changes by decking type

YellaWood advises installing wet treated boards tightly because shrinkage occurs as the boards dry. Trex specifies a 3/16-inch width-to-width gap for its composite decking. TimberTech Composite with CONCEALoc uses 3/16 inch, while TimberTech Advanced PVC calls for 1/8 to 1/4 inch depending on the fastening approach.

COMMON QUESTIONS

Deck board spacing calculator FAQ

01

Does this calculator determine the gap?

Yes. Choose a supported decking material or condition and the helper fills a side-to-side planning gap automatically. You can override it when your exact product guide requires a different value.

02

Is this the same as joist spacing?

No. This tool calculates the visible side-to-side gap between deck-board rows. Joist spacing is structural and depends on the decking system, framing design and applicable requirements.

03

Why can’t every composite board use one gap?

Composite and PVC products can have different requirements by product line and fastener system. The manufacturer’s current installation instructions control the final gap.
