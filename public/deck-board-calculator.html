HOW THE SPACING MATH WORKS

Calculate deck board spacing, rows and board count

This deck spacing calculator uses the deck dimension across the boards, the actual board face width and the intended gap between boards. Board width plus gap creates the repeating pitch. The tool then calculates how many rows are needed to cover the deck and how much of the width is made up of open gaps.

If you searched for a decking board spacing calculator or decking space calculator, this is the same board-gap calculation. It does not calculate structural joist spacing.

COMMON QUESTIONS

Deck board spacing calculator FAQ

01

Does board spacing change the board count?

Yes. The gap is part of the repeating width across the deck. A different gap can change the number of rows needed.

02

Is this the same as joist spacing?

No. This tool calculates the visible gap between deck-board rows. Joist spacing is structural and depends on the decking system, framing design and applicable requirements.

03

Why calculate linear feet too?

Linear feet converts the row layout into total decking length, which is useful when comparing the project with stock board lengths and leftover material.
