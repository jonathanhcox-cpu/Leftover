# Leftover

**Live site:** https://www.buildwithleftovers.com

Leftover is a free, reuse-first DIY material planner. Instead of starting with “How much should I buy?”, it starts with the material someone already has and helps answer:

- What can I make with these leftovers?
- Is there enough material to finish the project?
- Do the individual scraps, sheets, planks, or board lengths actually fit?
- If not, what is the remaining purchase gap?

## Supported materials

Leftover currently includes planning tools for:

- Tile
- Flooring
- Plywood
- Lumber
- Wallpaper
- Decking
- Trim

Project examples and reuse-planning guides are also available at:
https://www.buildwithleftovers.com/leftover-materials-project-planning

## Privacy and access

The site is free to use, requires no account, and core planning data is stored in the visitor's browser rather than uploaded to an account.

## Repository

The `public` folder contains the production pages, calculators, styles, scripts, and images. Run `node build.cjs` to copy the production files into `dist` for deployment.

Vercel is connected to this repository and deploys the `main` branch.
